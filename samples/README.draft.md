# Samples from a real OP-Z

This folder contains samples of the factory drum kits from my OP-Z. They were made at 90BPM by playing the drums at 4/16th intervals, in two passes for each kit, the first is 4 bars with pads 1-16 and the second has pads 17-24, followed by 2 bars of silence. They are played at root pitch with the envelope set to open and legato note-length, so should be the complete samples. A script (to be written) should convert them either into C source-code so they can be compiled into the plugin's shared object binary or into some type of data file that can be packaged along side it in the .vcvplugin archive. Either way, they will also need to be trimmed and have the silence clipped from the tails. Upon examining, it looks like the hits occur slightly off the mathematically derived beat positions, but what do I know, I'm just a developer, all I know is programming computers. I didn't even graduate high school, lol.
